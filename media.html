Rotate Raw Clips

This one generates a PowerShell + ffmpeg script rather than doing the work in-browser — re-encoding a full card dump is far faster natively. Add the clips to read their names, then run the script in the folder.

Run it as a saved .ps1 file (Download button below, then double-click or .\rotate-clips.ps1) — don't paste the script into a live PowerShell window. Pasting a long script can get cut off by a lost window focus, sleep, or a dropped keystroke. As a real script it runs start-to-finish as one process, and if it does get interrupted for any reason, just run the exact same file again — it writes to one fixed folder and skips any clip already finished, so nothing gets re-done and no extra folders pile up to merge later.

Drag the raw clips here (or click to browse) — only filenames are read, nothing uploads

"Compress only" always re-encodes (Fast mode has nothing to tag when there's no rotation), so Mode is locked to Re-encode.

Tested this directly against current ffmpeg (6.x): the metadata rotation tag it writes doesn't actually get embedded — the file comes out byte-identical, no rotation applied, while the script still reports "OK." This isn't a "some editors ignore it" caveat, it's confirmed non-functional on modern ffmpeg. Use Re-encode — it's the only mode verified to actually work.

Merge Multiple Rounds First

If you rotated/compressed clips in more than one batch (a game shot in rounds, footage handled in separate sessions), merge every Rotated_*/Compressed_* output folder into one before reviewing. Filename collisions are renamed with a _dup suffix — nothing is ever overwritten or lost, and any duplicates will show up during Review below so you can weed them out in the same pass.

This scans the parent folder itself, so it doesn't matter how many rounds there were — 2 or 12, it finds them all. Output lands in a new Merged_Final folder — point Review at that folder next.
